🔧 坐标系调试

飞控坐标系 (FLU)：

  • 🔵 蓝色箭头 = X轴（正面/前）
  • 🔴 红色箭头 = Y轴（左边）
  • 🟢 绿色箭头 = Z轴（上）

模型其他标识：

  • 🔵 蓝色镜头 = 机头朝向
  • 🔴 红色LED = 前侧螺旋桨
  • 🟢 绿色LED = 后侧螺旋桨

测试步骤：

  1. Roll测试：向右倾斜飞控 → 模型红灯应下沉
  2. Pitch测试：抬起机头 → 绿箭头应向上
  3. Yaw测试：顺时针旋转 → 模型应顺时针转
