Betaflight 飞控固件速查

基于 STM32F405 的飞控固件，模块化传感器/控制/通信，默认 1kHz 主循环。

怎么查： 左侧按模块直达，下面保留硬件/环境/FAQ 速记。少废话，直接可用。

文档章节

BSP层

I2C/SPI/UART 封装，系统时钟工具。

传感器驱动

ICM42688P/HMC5883L/BMP280 驱动与校准。

控制算法

Mahony + PID + Butterworth。

通信协议

ELRS/CRSF 接收机链路。

常用读取/解算/控制示例。

传感器、控制循环与 CPU 指标。

核心要点

  • 硬件平台: STM32F405 (Cortex-M4, 168MHz, 1MB Flash, 196KB SRAM)
  • 传感器:
    • ICM42688P: SPI, 8kHz, ±2000dps/±16g
    • HMC5883L: I2C, 75Hz, ±8Gauss
    • BMP280: I2C, 182Hz, 地址 0x76
  • 姿态解算: Mahony 1kHz，支持磁力计融合
  • 控制算法:
    • PID: 前馈、积分限幅、D 低通
    • 二阶 Butterworth：低通/陷波/带通
  • 通信: ELRS/CRSF，420000 bps，50-250Hz
  • 实时: 1kHz 主循环，传感器中断采集

开发环境配置

  1. 工具链: STM32CubeIDE 或 Keil MDK，ARM GCC，ST-Link 驱动。
  2. 获取代码: 
    git clone https://github.com/yourusername/betaflight-f405.git
cd betaflight-f405
  3. 编译 & 烧录:
    • IDE：打开工程，Build → Debug/Run。
    • 连接 ST-Link 到飞控板后烧录。
  4. 地面站: 打开 html/index.html，Chrome/Edge 通过 Web Serial 连接查看数据。

首次运行

安全提示: 首次运行请拆下螺旋桨，避免意外启动。
  1. 上电自检：约 1 秒完成传感器初始化。
  2. 陀螺仪校准：保持静止，看 LED 等待完成。
  3. 串口连地面站：115200 波特率。
  4. 磁力计校准：在地面站执行，旋转飞行器即可。

系统架构

分层架构，职责清晰：

硬件抽象层 (HAL)

STM32 HAL 封装 SPI/I2C/UART/DMA。

板级支持包 (BSP)

统一阻塞/非阻塞读写接口。

传感器驱动层

驱动 + 数据转换 + 校准。

控制算法层

姿态解算/滤波/PID，运行在 1kHz 调度器。

常见问题 (FAQ)

Q: 传感器初始化失败？

A: 先查供电和 SPI/I2C 引脚，示波器看时钟/数据；串口日志有错误码。

Q: 姿态解算漂移？

A: 重新校准陀螺仪（静止，采集 2000+ 样本）；Mahony Kp/Ki 可微调，增大 Ki 抗漂。

Q: PID 怎么调？

A: 从默认 P=45/I=80/D=30 开始。先调 P 到临界，再加 D 抑震荡，最后用 I 消除稳态误差。

Q: 如何查看实时数据？

A: 打开 html/index.html，用 Chrome/Edge Web Serial 连接串口，实时看 IMU/姿态/PID。
