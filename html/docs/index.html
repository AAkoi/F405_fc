Betaflight 飞控固件文档

本项目是一个基于 STM32F405 的飞行控制器固件，采用模块化设计，包含完整的传感器驱动、姿态解算、PID控制和通信协议支持。

快速开始： 选择左侧导航中的章节开始阅读详细的 API 文档。每个章节都包含完整的函数说明和使用示例。

文档章节

BSP层

板级支持包，包含 I2C、SPI、UART 通信接口和系统级功能。

传感器驱动

ICM42688P IMU、HMC5883L 磁力计、BMP280 气压计完整驱动。

控制算法

Mahony 姿态解算、PID 控制器、二阶 Butterworth 滤波器。

通信协议

ELRS/CRSF 接收机协议支持，支持 50-250Hz 更新率。

使用示例

完整的代码示例，包含传感器读取、姿态解算、PID控制等。

性能指标

传感器规格、控制性能、计算性能等详细指标。

主要特性

  • 硬件平台: STM32F405 (Cortex-M4, 168MHz, 1MB Flash, 196KB SRAM)
  • 传感器支持:
    • ICM42688P - 6轴IMU (陀螺仪±2000dps + 加速度计±16g, SPI接口, 最高8kHz采样)
    • HMC5883L - 3轴磁力计 (±8 Gauss, I2C接口, 75Hz采样率)
    • BMP280 - 气压计+温度计 (300-1100hPa, I2C接口, 182Hz采样)
  • 姿态解算: Mahony 互补滤波算法 (1kHz更新率, 支持磁力计融合)
  • 控制算法:
    • 三轴 PID 控制器 (支持前馈、积分抗饱和、D项滤波)
    • 二阶 Butterworth 数字滤波器 (低通/陷波/带通)
  • 通信协议: ELRS/CRSF 接收机协议 (420000 bps, 50-250Hz更新率)
  • 实时性能: 1kHz 主循环频率, 中断驱动的传感器数据采集

开发环境配置

  1. 安装工具链
    • STM32CubeIDE (推荐) 或 Keil MDK
    • ARM GCC 工具链
    • ST-Link 驱动程序
  2. 克隆项目 
    git clone https://github.com/yourusername/betaflight-f405.git
cd betaflight-f405
  3. 打开项目
    • 使用 STM32CubeIDE 打开 .project 文件
    • 或使用 Keil 打开 .uvprojx 文件
  4. 编译烧录
    • 点击 "Build Project" 编译
    • 连接 ST-Link 到飞控板
    • 点击 "Debug" 或 "Run" 烧录固件

首次运行

安全提示: 首次运行前，请确保飞行器电机已拆下或螺旋桨已卸除，避免意外启动造成伤害！
  1. 上电初始化 - 飞控板上电后会自动进行传感器初始化（约1秒）
  2. 陀螺仪校准 - 初始化时保持飞控静止，等待校准完成（LED指示）
  3. 连接地面站 - 使用 USB 转串口连接飞控，波特率 115200
  4. 查看数据 - 打开 html/index.html 查看实时传感器数据
  5. 磁力计校准 - 在地面站中执行磁力计校准（旋转飞行器）

系统架构

飞控系统采用 分层架构 设计，主要包含以下几个层次：

硬件抽象层 (HAL)

基于 STM32 HAL 库，提供统一的硬件接口，支持 SPI、I2C、UART、DMA 等外设。

板级支持包 (BSP)

封装底层通信接口，提供阻塞/非阻塞模式的读写操作，简化上层调用。

传感器驱动层

实现各传感器的初始化、数据读取、校准等功能，提供物理单位转换。

控制算法层

包含姿态解算、PID 控制、滤波器等核心算法，运行在 1kHz 主循环中。

常见问题 (FAQ)

Q: 传感器初始化失败怎么办？

A: 检查硬件连接，确认 SPI/I2C 引脚配置正确。使用示波器或逻辑分析仪检查时钟和数据线。查看串口日志输出的错误代码。

Q: 姿态解算漂移严重？

A: 首先重新校准陀螺仪（静止状态下采集2000+样本）。如果仍然漂移，检查 Mahony 算法的 Kp/Ki 参数，适当增加 Ki 可以减少漂移。

Q: PID 参数如何调优？

A: 建议从默认参数开始 (P=45, I=80, D=30)，逐步调整。先调 P 参数直到响应迅速但不震荡，再增加 D 抑制超调，最后调 I 消除稳态误差。

Q: 如何查看实时数据？

A: 打开 html/index.html 文件，使用 Web Serial API 连接飞控串口（需要 Chrome/Edge 浏览器）。可实时查看传感器数据、姿态角、PID 输出等。
